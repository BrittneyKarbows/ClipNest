# 剪藏 ClipNest 1.2.0

剪藏是一款中文原生 macOS 剪贴板管理工具。复制过的文字、链接、图片和文件位置，都可以在底部卡片面板中搜索、收藏和再次粘贴。历史保存在本机，无需账号。

本次更新让外观和历史管理更灵活，并重新整理了设置界面。

## 本次更新

- **浅色与深色**：可手动选择，也可跟随 macOS 自动切换。面板与设置同步更新，保留来源应用图标和专属色条。
- **自动清理历史**：可选择 7 天、1 个月、3 个月、6 个月或 1 年，也可永不自动删除。按最后复制时间计算，收藏和分类内容保留。默认关闭，选择周期会影响已有过期记录时先确认。
- **设置重新分类**：通用、外观、快捷键与粘贴、历史记录、隐私、关于与联系，按功能独立分组。
- **开发者联系**：新增邮箱与 GitHub 主页，方便反馈问题和建议。

原有的搜索、收藏、分类、来源图标与色条、图片文件预览、自定义快捷键、登录启动、菜单栏显示和应用排除继续保留。

## 下载

- `ClipNest-1.2.0-arm64.zip`：Apple Silicon 安装包，解压后将应用拖入“应用程序”。
- `ClipNest-1.2.0-source.zip`：源码、Xcode 工程、图标资源、构建脚本、检查脚本和文档。
- `SHA256SUMS.txt`：以上压缩包的 SHA-256 校验值。

要求 macOS 13 或更新版本。默认呼出快捷键为 **⌘⇧V**，可在设置中修改；升级会沿用已有快捷键和历史数据。

## 升级说明

请先完整退出旧版，再替换“应用程序”中的 `ClipNest.app`。历史数据库与偏好保存在应用包外，更新不会主动启用自动过期清理。

当前包使用 ad hoc 签名，未经 Developer ID 签名及 Apple 公证。更新后如直接粘贴显示未授权，请在系统辅助功能中移除旧条目，添加当前 `/Applications/ClipNest.app` 并开启，再完整退出并重新打开。跨设备运行可能受到 macOS 安全检查限制，也可自行构建源码。

自动清理在应用运行时检查，退出期间不清理；收藏和分类中的记录受保护，数量上限独立生效。历史存储未加密，不含云同步。
