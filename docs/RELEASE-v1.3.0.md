# 剪藏 ClipNest 1.3.0

本次更新重新整理了界面主题，让默认外观更简洁，并支持自由选择强调色。

## 更新内容

- **中性浅色界面**：背景调整为黑白灰，移除原有米黄色底色与橙色默认主题。
- **默认黑白**：导航选中、操作按钮、收藏状态和剪贴卡片边框默认使用黑白强调色。
- **六种颜色可选**：在“设置 → 外观 → 强调色”中选择黑白、蓝色、紫色、绿色、玫红或青色。例如选蓝色后，卡片选中边框和相关操作会同步变蓝。
- **即时生效并保存**：切换后面板和设置同步更新，重新启动仍保留选择。
- **明暗模式兼容**：浅色、深色与跟随系统模式都能使用强调色，并针对深色背景调整颜色亮度。
- **保留来源识别**：来源 App 的真实图标和专属色条继续用于区分内容来源。

现有历史、收藏、分类、快捷键和保留周期继续沿用。此次没有修改剪贴板捕获、历史存储、自动清理或直接粘贴逻辑。

## 安装体验

应用采用 DMG 分发。安装窗口使用黑白剪贴卡片主题，将左侧剪藏拖入右侧“应用程序”即可安装；支持 Retina 背景。源码继续使用 ZIP，应用安装不需要解压 ZIP。

## 验证

123 项核心隔离检查通过，覆盖颜色偏好迁移、六色持久化、无效值回退及明暗背景上的对比度。已实测浅色黑白、蓝色选中边框、深色兼容和重启保存。

## 下载与升级

- `ClipNest-1.3.0-arm64.dmg`：Apple Silicon / macOS 13+ DMG 安装包，附 MIT 许可证。
- `ClipNest-1.3.0-source.zip`：完整源码、Xcode 工程、图标、构建和测试脚本及文档。
- `SHA256SUMS.txt`：附件的 SHA-256 校验值。

请先退出旧版再替换“应用程序”中的 `ClipNest.app`。历史和偏好保存在应用包外，会继续沿用。

安装包使用本地 ad hoc 签名，尚未经过 Developer ID 签名及 Apple 公证。更新后如直接粘贴提示未授权，请在系统辅助功能中移除旧条目，添加当前 `/Applications/ClipNest.app` 并开启，再完整退出并重新打开。
