# 剪藏 ClipNest 1.4.0

这次新增批量粘贴，集中处理多条散单号更方便。

## 更新内容

- 面板顶部新增“多选”，文字和链接卡片可逐条勾选并显示编号。
- 按勾选顺序用一个空格拼接，一次粘贴到原应用。例如 `000123 SF456 AB789`，保留前导零。
- 支持“复制所选”“粘贴所选”“全选文字”和“清空”；搜索或切换分类保留选择。
- 回车粘贴所选，Shift＋回车仅复制；空格或 ⌘1–9 勾选，搜索框外 ⌘A 全选当前结果，Esc 退出多选。
- 仅去掉各条首尾空白，保留内部空格和换行。图片、文件不参与文字拼接。
- 合并结果超过 1 MB 或所选记录已不存在时显示提示，不覆盖原剪贴板；合并内容不额外写入历史。
- 修正面板已处理键盘事件仍继续传递的问题。

## 使用方法

把光标放到目标输入框 → 用快捷键呼出剪藏 → 点击“多选” → 按需要的顺序勾选 → 点击“粘贴所选”或回车。

仅复制会保留选择，成功直接粘贴后清空选择。直接粘贴仍使用现有权限与目标应用焦点恢复流程。

## 验证与安装

148 项核心隔离检查、26 项直接粘贴状态检查通过。沿用黑白剪贴卡片主题 DMG 与自选强调色。

- `ClipNest-1.4.0-arm64.dmg`：Apple Silicon / macOS 13+ 安装包。
- `ClipNest-1.4.0-source.zip`：源码、Xcode 工程、构建与测试脚本、文档。
- `SHA256SUMS.txt`：附件校验文件。

先退出旧版，再拖入“应用程序”替换。已有历史、收藏、分类和偏好继续沿用。当前为 ad hoc 签名，尚未完成 Developer ID 签名与 Apple 公证。若系统未沿用直接粘贴授权，请按设置中的说明重新添加当前应用，再完整退出并重启。
