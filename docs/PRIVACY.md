# 数据与隐私

本文对应剪藏 1.3.0 的实际实现。

## 记录内容

应用运行且未暂停时，轮询系统剪贴板。支持的记录包括文字、HTTP/HTTPS 链接、图片与本地文件位置，并保存复制时间、来源应用名称和 Bundle ID。单张可读取的本地图片文件可额外缓存图片内容。

来源应用图标与配色仅从本机解析，不联网下载。普通文本里的路径不会自动读取，远程图片链接不会被下载。

## 存储与网络

历史存储在 `~/Library/Application Support/ClipNest/` 的本地 SQLite 数据库中。偏好设置使用 macOS UserDefaults，登录启动由系统登录项服务管理。

应用没有历史上传、云同步或分析上报功能。点击“联系我们”的邮箱或 GitHub 链接，会将相应链接交给邮件应用或浏览器处理，不会自动附带或发送剪贴板内容。

数据库未加密；目录限制为当前用户访问，数据库文件权限为 0600。拥有相应本机权限的软件、用户或系统备份仍可能访问这些数据。备份或迁移时，请先退出应用，再复制完整数据目录及 SQLite 关联文件。

## 暂停与排除

可以暂停新记录，或排除指定应用。默认排除常见密码管理器，并忽略带有 Concealed、Transient、AutoGenerated 或已识别密码管理器标记的剪贴板内容。

应用无法可靠识别所有未标记的密码或敏感信息。复制私人资料前，可主动暂停或排除来源应用。更改排除列表不会追溯删除已有内容。

## 删除

可以删除单条记录，或清空未收藏、未加入分类的历史。数量上限和自动过期清理均保护收藏与分类内容。自动过期清理默认关闭，启用后按最后复制时间计算。

清空与删除不能通过应用撤销。SQLite 空闲页、系统备份和磁盘快照可能保留副本，应用不提供取证级安全擦除。

## 系统权限

直接粘贴需要当前运行构建具备相应辅助功能与按键权限。未授权时仍可仅复制，再手动粘贴。应用不自动授予权限，不修改系统隐私数据库。
